## 🚀 Getting Started

- Scan QR Codes – Real-time scanning with camera integration, supporting multiple QR formats.
- Generate QR Codes – Create custom QR codes with ease.
- Save & Share – Users can save generated QR codes to the device gallery and share them seamlessly.
- Clipboard Support – Copy scanned/generated content directly to the clipboard.
- Arabic Localization – Full support for Arabic users for better accessibility.
- User-Friendly Interface – Smooth navigation and intuitive UI interactions.
- Machine Learning Integration (Optional) – Advanced scanning features using ML Kit for more accurate detection.
